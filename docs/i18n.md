# 国际化

站点使用 VitePress 内置的 locale 路由进行静态国际化，不依赖额外的客户端翻译库。

## 语言与路由

| 语言     | `lang`  | 路径   | 说明     |
| -------- | ------- | ------ | -------- |
| English  | `en`    | `/`    | 默认语言 |
| 简体中文 | `zh-CN` | `/zh/` | 中文版本 |

两个入口都会在构建阶段生成独立 HTML，并带有对应语言的页面标题、描述和 Open Graph 元数据。页头的语言入口用于在两个版本之间切换。

## 内容组织

- `.vitepress/config.ts`：语言路由和站点级元数据。
- `site/index.md`、`site/projects/index.md`、`site/publications/index.md`、`site/experience/index.md`、`site/blogs/index.md`、`site/contact/index.md`：英文页面入口（对应 `site/zh/` 下的中文页面）。
- `src/i18n/sources/en.ts` 与 `src/i18n/sources/zh.ts`：站点级界面文案，并将每个路由文件映射为 `messages.<route>`。
- `src/data/profile.ts`：首页身份、联系方式、新闻、研究方向摘要、代表论文与公共技能。
- `src/data/projects.ts`：按机器人与具身智能、LLM 智能体、全栈 AI 三类组织的十个项目及图片/占位元数据。
- `src/data/publications.ts`：论文与专利。
- `src/data/experiences/`：经历页数据拆为 `professional.ts`、`research.ts`、`education.ts`、`honors.ts` 四个分组文件，类型与数据同文件；`index.ts` 组装页面文案与四组内容。
- `src/data/blogs.ts`：博客索引文案。
- `src/data/contact.ts`：联系页说明、联系方式、外部主页与 CV 路径。
- `src/data/common/news.ts`：首页使用的双语动态。
- `src/data/common/skills.ts`：首页和经历页共用的双语技能数据。

`src/data` 顶层保留 `profile.ts`、`projects.ts`、`publications.ts`、`blogs.ts`、`contact.ts` 五个路由文件，经历页数据位于 `src/data/experiences/` 目录。每个路由对象包含：

- `label`：页面标题、区块标题、按钮和辅助标签。
- `content`：导语、列表及页面主体内容。
- 顶层常规字段：无法归入标题或主体的稳定数据，例如 `email`、`phone`、`cvHref`。

每个路由文件同时包含对应类型与中英文数据。`profile.ts` 从 `common` 组装新闻和技能；经历页通过 i18n 组装复用首页中的公共技能，这是唯一的跨路由公共数据例外。

- `src/hooks/useSiteLocale.ts`：将 VitePress 当前语言映射为站点内容语言，返回当前语言的 `messages`，并提供 `path()` 生成当前语言的页面路由（如 `/experience/` ↔ `/zh/experience/`）。

路由组件只读取自己的命名空间：Home 使用 `messages.home`，Experience 使用 `messages.experience`，其余路由同理。展示组件通过类型化 props 接收数据，不直接选择语言或拼装其他路由内容。

页头导航将六个分组映射为真实路由，并依据当前语言生成 `/experience/`、`/projects/` 等路径；语言切换会保留当前页面的对应语言版本（如英文 `/experience/` 切换到 `/zh/experience/`）。

新增或修改公开内容时，应同步更新对应路由文件的英文和中文对象。新增语言时，还需要在 VitePress `locales`、`site/` 页面入口、`siteInfos` 和六个路由数据映射中注册该语言。
